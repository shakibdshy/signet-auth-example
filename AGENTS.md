### Issue tracker

Issues for this repo live in GitHub Issues at `shakibdshy/signet-auth-example`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles map to identically named GitHub labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.
